## P1 MVP（2027-01-04 → 2027-03-14）

- PostgreSQL + Redis，多实例部署；Colyseus 替换自实现房间层
- 正式账号与支付（Stripe / 台湾在地支付）；高香等付费道具（不加功德）
- 日式神社、韩式山寺场景包
- 祖先堂付费纸扎与永久灵位（不加功德）、推送提醒（忌日 / 清明）；会员专属禅房（高品质念诵与空间音效）
- [x] 泥生 GPU 实例化（提前完成）：96 人同殿整帧 1,694 → 148 draw calls，远处半细分模型，名牌图集
- 高斯泼溅远景层；场景包上传后自动压缩、生成 LOD、预算检查
- 压测 10,000 人同时在线不掉线
