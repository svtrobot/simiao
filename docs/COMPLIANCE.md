# 合规与地区模式

以下是产品层面的实现说明，不是法律意见。各市场上线前请当地律师确认。

大陆规则依据《互联网宗教信息服务管理办法》（2022-03-01 施行）第十七、十八条：不得在互联网上直播或录播拜佛、烧香、诵经等宗教仪式，不得在互联网上设立宗教活动场所。大陆部署是一套独立环境（数据不互通），定位为「东方文化冥想 + 民俗祈福 + 网络祭扫」。

## 合规模式（每个场景、每座寺）

实际模式 = 地区允许仪式 **且** 场景支持 `ritual` **且** 寺庙没有设为 `cultural`，否则为 `cultural`。

- `cultural` 模式下，客户端隐藏仪式按钮，服务器同时拒绝仪式消息与求签接口（双重保证，见 `server/domain/compliance.js` 和测试）。
- 保留：行走、静坐冥想、预设致意、祈福牌、随喜。

## 开庙审核

- 名称含寺、庙、宫、观、庵、祠、神社等字样者，必须是「寺院 / 道观 / 神社」类型并附宗教活动场所登记证，否则不予受理，只能改以「文化空间」名义开设。
- 名称与简介不得含「消灾」「改命」「保证灵验」「不供奉会倒霉」「功德充值」等恐吓或承诺灵验的说法。
- 家族祠堂默认仅凭邀请进入。

## 用户内容

- 祈福牌 60 字以内，默认匿名；含链接、联系方式、营销用语的拒收。机审之后的人审与外部审核接口在 P1 接入。
- 内容涉及自伤念头时：不公开悬挂，只回给本人一段温和的话和当地心理援助热线。

## 功德与付费

- 功德只来自静坐、礼拜、仪式和善念，由服务器计算、限速、每日封顶。
- 付费道具（P1）不增加功德；签文好坏与付费无关；不做抽卡；不卖「消灾」「改命」。
