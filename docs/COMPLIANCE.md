# 合规与地区模式

以下是产品层面的实现说明，不是法律意见。各市场上线前请当地律师确认。

## 地区（`REGION`）

| | `tw` | `overseas` | `cn` |
|---|---|---|---|
| 时区（每日额度重置） | Asia/Taipei | UTC | Asia/Shanghai |
| 界面 | 繁体 | 繁体 | 简体 |

大陆规则依据《互联网宗教信息服务管理办法》（2022-03-01 施行）第十七、十八条：不得在互联网上直播或录播拜佛、烧香、诵经等宗教仪式，不得在互联网上设立宗教活动场所。大陆部署是一套独立环境（数据不互通），定位为「东方文化冥想 + 民俗祈福 + 网络祭扫」。

## 合规模式（每个场景、每座寺）

实际模式 = 地区允许仪式 **且** 场景支持 `ritual` **且** 寺庙没有设为 `cultural`，否则为 `cultural`。

- `cultural` 模式下，客户端隐藏仪式按钮，服务器同时拒绝仪式消息与求签接口（双重保证，见 `server/domain/compliance.js` 和测试）。
- 保留：行走、静坐冥想、预设致意、祈福牌、随喜。

## 开庙审核

- 名称含寺、庙、宫、观、庵、祠、神社等字样者，必须是「寺院 / 道观 / 神社」类型并附宗教活动场所登记证，否则不予受理，只能改以「文化空间」名义开设。
- 名称与简介不得含「消灾」「改命」「保证灵验」「不供奉会倒霉」「功德充值」等恐吓或承诺灵验的说法。
- 家族祠堂默认仅凭邀请进入。

## 用户内容

- 祈福牌 60 字以内，默认匿名；含链接、联系方式、营销用语的拒收。机审之后的人审与外部审核接口在 P1 接入。
- 内容涉及自伤念头时：不公开悬挂，只回给本人一段温和的话和当地心理援助热线。

## 点灯

- 仪式模式：光明灯、药师灯、长明灯；文化参访模式（含大陆）只有不带佛号的「祈福灯」，文案用「点亮 / 亮至 / 熄灭」，不用「供奉 / 圆满」。
- 灯墙公开显示的名字一律隐去中间的字（王○明），不显示点灯人；全名只有点灯人本人和祈福卡持有者能看到。
- 灯牌文字与祈福牌同一套机审；涉及自伤念头时灯照样点亮，但心愿不上墙、不进祈福卡，只回给本人温和的话和热线。
- P0 不收费：每盏灯七天，期满前两天可续，每人同时最多三盏。只有「为他人点灯」记功德（为他人祈福），为自己点灯不记；P1 付费灯同样不记。

## 黄历与本命佛

- 黄历是民俗参考：宜忌按建除十二神给日常事项，不写吉凶断语；「犯太岁」「今日相冲」只用善意提醒的语气，不推付费化解（3.3）。
- 本命佛、佛诞等佛教节日只在仪式模式出现；文化参访模式（含大陆）只保留生肖、节气与民俗节日，每日一句也换成不带宗教用语的版本。
- 生日是选填的个人资料：只用于本人的黄历，不进房间广播（publicView），可随时清除。

## 禅房与抄经

- 禅房是单人空间：进入时离开大殿房间，别人看不到你；静坐分钟由服务端按心跳记录，锁屏或切走的时段不算，同一账号同时在大殿静坐不重复计。
- 抄经（《心经》）只在仪式模式提供；文化参访模式（含大陆）只有不带宗教内容的「习字」（陶渊明《饮酒·其五》），大陆界面称「静室」。服务器按模式拒绝不允许的底本。
- 抄经计功德：服务端限速（每字至少约 0.9 秒）、5 字一个单位、每日最多记一部《心经》（260 字）；写多了可以继续写，只是不再记。重试不会重复计。
- 描红进度只给本人看，不进房间广播；写好的字只存在本机，用来生成本人的抄本图。

## 祖先堂与烧纸

- 家堂是私人空间：灵位、照片、寄语只有凭邀请链接加入的家人看得到，不进大殿房间广播；邀请预览只显示家堂名和邀请人，不显示逝者姓名。建立者可换链接（旧链接失效）、移出家人。
- 仪式模式：献花、供果、点烛、上香、奉茶，以及烧纸（银纸、元宝、莲花）。文化参访模式（含大陆）只有献花、供果、点烛与寄语（文明祭扫），不上香、不烧纸；服务器按模式拒绝。
- 烧纸不记功德、文案不承诺灵验（只说「心意已送达」）；服务端限速（约每张 0.9 秒）、每人每日计数上限 360 张。P1 的付费纸扎同样不记功德。
- 献供：每位亲人每天第一次献供记一次功德，每天最多 3 位（慎终追远）。
- 寄语与祈福牌同一套机审；涉及自伤念头时只给本人看，并回温和的话和热线。

## 账号与个人资料

- 保存修行只用通行密钥（服务器只存公钥）与恢复码（只存哈希），不收集电话、email 或真实姓名。
- 恢复码只显示一次；找回接口按来源地址限速。各设备可单独登出。

## 功德与付费

- 功德只来自静坐、礼拜、仪式和善念，由服务器计算、限速、每日封顶。
- 付费道具（P1）不增加功德；签文好坏与付费无关；不做抽卡；不卖「消灾」「改命」。
