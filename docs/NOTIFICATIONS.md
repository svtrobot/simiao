# 提醒（Web Push）

对应设计文档 4.1：早 8 点黄历、晚上静坐；以及祖先堂的忌日、冥诞、清明、中元、寒衣节。

## 用户看到什么

「我的修行 → 提醒」里三个开关，按「开启提醒」后浏览器询问通知权限：

| 时段（用户本地时间） | 内容 | 默认 |
|---|---|---|
| 08:00 | 当天有家人的纪念日 → 「今天是祖父 王大明的忌日（7 周年）」；否则 → 「早安 · 农历十月初三」+ 今日一句 | 开 |
| 20:00 | 明天是家人的纪念日或清明 / 中元 / 寒衣节 → 「明天是……」 | 开（属于「家人」开关） |
| 22:00 | 「睡前，静坐五分钟？」 | 关 |

- 一天最多两则；不提断签、不催促、不做「你已经 N 天没来」这类话（4.1「不惩罚」）。
- 点通知直接到对应的地方：`/?go=ancestor`、`/?go=zen`、`/?go=almanac`。
- 祖先堂里有纪念日时，标题下方有「到时候提醒我」。
- iPhone / iPad 只在「加入主画面」后的网页 App 里收得到（iOS 16.4+），界面会提示。

## 技术

- `server/domain/push.js`：RFC 8291（aes128gcm）加密与 RFC 8292 VAPID（ES256 JWT）都用 `node:crypto`，零依赖。
- 推播内容端到端加密：Google / Apple / Mozilla 的推播服务看不到内容（包括逝者姓名）。
- VAPID 金钥第一次启动时自动产生，存在数据里（`meta/vapid`）。**备份数据卷时一起备份**；金钥换了，用户要重新开启提醒。多实例部署用环境变量 `VAPID_KEYS`（`{"jwk":…,"publicKey":…}`）固定同一对金钥。
- `PUSH_SUBJECT`：给推播服务的联系方式（`https://…` 或 `mailto:`），默认取 `PUBLIC_ORIGIN`。不要填个人邮箱以外不想公开的地址。
- 排程：`server/index.js` 每分钟跑一次 `push.tick()`，按每台设备的时区判断当地 8 / 20 / 22 点；同一时段一天只判断一次，服务器在 08:00 正好重启也会在 8 点这一小时内补发。`PUSH=off` 可关闭排程。多实例时改成单一排程任务（P1 基础设施）。
- 推播服务回 404 / 410 的订阅自动删除。
- 前端：`client/sw.js`（只处理推播，不做离线缓存）、`client/manifest.webmanifest`、`client/icons/`（`node tools/make-icons.mjs` 程序化生成）。

## 地区

- 需要 HTTPS。
- 中国大陆：Chrome 的推播走 FCM，大陆不可达；大陆版需改接厂商推送或小程序订阅消息（另案）。
